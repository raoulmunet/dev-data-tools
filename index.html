Install the complete suite locally

Clone the portal, run the installer, then start the local suite:

git clone https://github.com/raoulmunet/dev-data-tools.git cd dev-data-tools chmod +x install-suite.sh ./install-suite.sh ./run-local.sh

The installer keeps all repositories as siblings. The local server starts from their common parent so the portal can load every tool without rebuilding anything.
